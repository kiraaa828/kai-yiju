# 第一届产品方案：`v0.1.0`

## 一句话定义

为宿舍和同学聚会推荐马上能玩的游戏，并按需生成可以直接复制到豆包等 AI 工具中的主持人指令。

## 目标用户

- 大学生
- 4～12 人
- 宿舍、客厅、餐厅或简单户外场景
- 单局 5～30 分钟
- 默认不涉及酒精、危险动作和羞辱性惩罚

## 当前内容规模

- 36 个聚会和酒吧游戏
- 24 条互动挑战
- 互动挑战分为破冰、表演、创意、团队和轻聊
- 酒吧模式下喝酒完全可选，不把饮酒作为惩罚或胜负条件
- 所有互动挑战默认允许无理由跳过，不使用羞辱、隐私和危险惩罚
## 核心流程

```text
首页
  -> 选择人数
  -> 选择场地、道具、时长和氛围
  -> 推荐 3 个游戏
  -> 查看规则
  -> 选择人工主持或复制 AI 主持人指令
```

## 推荐结果

每次最多推荐 3 个方向：

- 稳一点：规则简单，适合大部分人
- 笑一点：更容易活跃气氛
- 换换口味：最近没玩过或类型稍有变化

每个结果展示推荐原因、人数、时长、道具和场地。

## AI 主持人选项

AI 主持人不是默认模式，而是用户主动选择的选项：

- 没有选择 AI 主持人时：显示人工主持步骤
- 选择 AI 主持人时：额外提供“复制 AI 主持人指令”
- 应用不启动、不控制、不接入豆包
- 指令仍由用户手动粘贴到豆包或其他 AI 工具

## 第一版不做

- 不接入豆包、微信或任何第三方通话系统
- 不做用户账号
- 不做后端数据库
- 不做实时协作
- 不做商业桌游完整规则
- 不复制第三方网站的规则原文
- 不提供酒精和危险挑战模式

## 验收标准

- 手机上可在 30 秒内完成选择
- 人数、场地、道具和时长筛选准确
- 每次给出最多 3 个推荐结果
- 每个游戏都有规则、主持步骤和安全提示
- 支持 AI 主持的游戏可以一键复制完整指令
- 使用 Node 内置测试可验证推荐逻辑
- 可以直接部署到 GitHub Pages
